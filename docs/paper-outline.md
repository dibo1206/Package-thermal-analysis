## 1쪽에 담을 내용

1페이지라 **다 넣을 수 없다.** 아래 구성이 기본안이다.

### 제목 후보
1. TIM 보이드가 패키지 칩 온도에 미치는 영향과 물리 결합 대리모델
2. 유한차분 열해석 기반 TIM 보이드 영향 분석 및 학습 데이터 절감
3. 1차원 열저항 기준선을 결합한 패키지 열 대리모델의 데이터 효율

### 구성 (문장 수는 대략)

**서론 (3~4문장)**
- 패키지 발열이 국부적으로 몰리면 최고 온도가 평균보다 크게 높아진다
- TIM 보이드 같은 공정 불량은 이를 더 악화시키지만, 1차원 열저항 모델과 기존 해석해는 TIM 을 균일하다고 가정해 이를 표현하지 못한다
- 반복 해석은 비용이 커서 대리모델이 쓰이지만, 순수 데이터 방식은 많은 해석 결과를 필요로 한다
- 본 연구는 (1) 보이드 영향을 정량화하고 (2) 1차원 해석값을 기준선으로 결합했을 때 필요한 학습 데이터가 얼마나 줄어드는지 제시한다

**방법 (3~4문장)**
- 다이/TIM/리드 3층 단면을 0.025mm 격자의 2차원 유한차분으로 해석. 윗면 대류, 바닥·옆면 단열
- 해석기는 발표된 확산 저항 해석해와 비교해 검증 (최세격자 오차 0.03% 이내)
- 보이드는 TIM 격자 일부를 공기(0.026 W/m·K)로 치환해 모사
- 조건 7개를 무작위로 800건 생성(학습 640/검증 160), 두 대리모델을 비교:
  (A) 조건 → 최고 온도 직접 학습, (B) 최고 온도 = 1D 해석값 + 발열 × 학습한 1W당 추가 온도

**결과 (4~5문장 + 그림 2개)**
- 같은 발열량이라도 1mm 핫스팟은 균일 발열 대비 최고 온도가 5.3℃ 높다
- 보이드 2mm 가 핫스팟 바로 위에 있으면 +14.6℃, 2mm 옆으로 벗어나면 +0.1℃ (그림 1)
- 검증 160건 평균 오차: 1D만 14.8℃, 방법 A 1.5℃, 방법 B 1.0℃
- 목표 2.0℃ 달성에 방법 A 는 400건, 방법 B 는 200건 (그림 2)
- 목표 1.5℃ 는 방법 A 가 640건으로도 도달하지 못함

**결론 (2문장)**
- 보이드 영향은 위치에 강하게 의존하며 균일 TIM 가정 모델로는 예측 불가
- 1차원 해석값을 기준선으로 분리하면 같은 정확도에 필요한 해석 횟수가 절반으로 줄어든다
