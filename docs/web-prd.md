| 항목 | 내용 |

---

## 1. 한 줄 요약

패키지 조건과 TIM 보이드를 입력하면 칩 최고 온도를 **즉시 예측하고, 그 예측을 얼마나 믿을 수 있는지까지 보여주는** 웹 도구.
대리모델이 아니면 현실적으로 할 수 없는 기능(위험 지도, 허용 기준 역산)을 담는다.

## 2. 배경

### 지금까지 한 것
- 다이/TIM/리드 단면 2D 유한차분 해석기 (외부 해석해와 0.03% 이내 일치)
- 보이드 조건 800건 데이터 (학습 640 / 검증 160)
- 대리모델 `최고 온도 = 1D 해석값 + 발열 × AI가 학습한 1W당 추가 온도`
  - 검증 평균 오차 0.99℃, 최대 11.2℃
  - 같은 정확도(2.0℃)에 필요한 데이터가 AI 단독의 절반

### 풀려는 문제
결과가 그림과 숫자로만 있어서, 보는 사람이 **직접 조건을 바꿔볼 수 없다.**

### 짚고 가야 할 반론
2D 해석은 한 번에 평균 **3.1초**(보이드 없으면 1.4초)다.
조건 하나를 넣고 온도 하나를 보는 기능만 있으면 **"그냥 해석을 돌리면 되지 않나?"** 라는 질문에 답할 수 없다.

→ 대리모델의 가치는 **계산을 수천 번 해야 할 때** 생긴다. 이 도구의 핵심 기능은 그 지점에 둔다.

| 작업 | 2D 해석 | 대리모델 |
|---|---|---|
| 조건 1개 | 3.1초 | 0.01초 미만 |
| 위험 지도 2,000칸 | 약 1시간 40분 | 1초 미만 |

## 3. 목표와 비목표

### 목표
1. 조건을 바꾸면 최고 온도와 **불확실성 범위**를 즉시 보여준다
2. 대리모델로만 가능한 기능 두 가지를 제공한다: **보이드 위험 지도**, **허용 보이드 크기 역산**
3. 버튼 하나로 실제 2D 해석을 돌려 **AI 예측과 정답을 나란히** 보여준다
4. 학습 범위 밖 입력과 오차가 큰 조건을 **스스로 경고**한다
5. 휴대폰에서 QR로 열어도 쓸 수 있다

### 비목표 (이번에 하지 않는 것)
- 3D 해석, 실측 데이터 비교
- 다른 재료·층 구조(HBM 적층 등) 입력
- 회원 가입, 결과 저장, 여러 사람이 공유하는 기록
- 브라우저 안에서 모델 재학습
- 능동 학습 (→ 9장, 다음 연구로 분리)

## 4. 사용자

| 사용자 | 상황 | 원하는 것 |
|---|---|---|
| **교수님·대학원생** (1순위) | 컨택 메일 링크를 열어 1~2분 본다 | 무엇을 했고, 얼마나 정확하고, 어디서 틀리는지 빨리 파악 |
| **포스터 관람객** | 휴대폰으로 QR 접속 | 슬라이더 몇 번 움직여 보고 핵심을 이해 |
| **가상의 공정 엔지니어** | 보이드 검사 기준을 고민 | "이 보이드는 불량인가?" 에 대한 답 |
| **본인** | 포스터 발표, 면접 | 질문이 오면 화면으로 바로 시연 |

## 5. 핵심 시나리오

1. **교수님**: 링크를 연다 → 기본 조건의 예측 온도와 ± 범위가 보인다 → "정답 확인"을 누른다 → 3초 뒤 실제 해석과 오차가 나온다 → 아래로 내려 위험 지도를 본다
2. **관람객**: 보이드 위치 슬라이더를 핫스팟 쪽으로 옮긴다 → 온도가 크게 오르는 것을 본다 → 핫스팟에서 멀어지면 영향이 거의 없다는 것을 확인한다
3. **공정 엔지니어**: "온도 한계 85℃" 를 입력한다 → 핫스팟 위 보이드는 최대 몇 mm까지 허용되는지 답을 받는다
4. **잘못된 사용**: TIM 두께를 학습 범위 밖으로 넣으려 한다 → 입력이 막히거나 경고가 뜬다

## 6. 기능 요구사항

우선순위: **P0** 없으면 공개하지 않음 / **P1** 포스터 전까지 / **P2** 여유가 있으면

### F1. 조건 입력 (P0)
학습 데이터의 범위를 그대로 슬라이더 범위로 쓴다.

| 입력 | 범위 | 단위·비고 |
|---|---|---|
| 총 발열 | 1 ~ 15 | W |
| 핫스팟 크기 | 0.25 ~ 10 | mm, 다이 가운데 고정 |
| TIM 두께 | 0.05 ~ 0.25 | mm, 0.025mm 단위 (격자) |
| TIM 열전도율 | 1 ~ 10 | W/m·K |
| 방열판 저항 | 0.3 ~ 3 | K/W |
| 보이드 폭 | 0 또는 0.25 ~ 4 | mm, 0 = 보이드 없음 |
| 보이드 위치 | 다이 안 | mm, 다이 왼쪽 끝 기준 |

- 기본값은 지금까지 써온 기준 조건 (5W, 1mm 핫스팟, TIM 0.05mm / 3 W/m·K, 방열판 1 K/W)
- **완료 기준**: 범위 밖 값은 입력할 수 없다

### F2. 즉시 예측 + 불확실성 (P0)
- 예측 최고 온도, 1D 공식 값, 두 값의 차이(핫스팟·보이드 때문에 추가된 온도)를 표시
- 가우시안 과정의 예측 분산으로 **95% 범위**를 함께 표시 (예: `43.1℃ ± 1.2℃`)
- **완료 기준**
  - 응답 0.5초 이내
  - **범위가 실제로 맞는지 측정한다**: 검증 160건 중 95% 범위 안에 정답이 들어오는 비율이 90~98% 사이여야 한다
  - 벗어나면 범위 크기를 보정한다. 보정 계수는 **학습 데이터 안의 교차검증으로만** 정한다 (검증셋으로 정하지 않는다)

### F3. 경고 (P0)
| 조건 | 표시 |
|---|---|
| 불확실성이 큼 (기준값은 F2 측정 후 정함) | "이 조건은 AI가 자신 없어합니다. 정답 확인을 권장합니다" |
| 보이드가 핫스팟을 덮음 | "오차가 가장 큰 영역입니다 (검증 평균 1.7℃, 최대 11.2℃)" |
| 항상 | "2차원 단면 해석 기준. 보이드는 깊이 방향으로 이어진 띠로 계산되어 실제 원형 보이드보다 영향이 크게 나옵니다" |

### F4. 정답 확인 (P0)
- 버튼을 누르면 같은 조건으로 2D 해석을 실행 (1~4초, 진행 표시)
- 결과: 실제 최고 온도, AI 예측, 오차, 실제 값이 95% 범위 안에 들어왔는지
- 단면 온도 지도 (다이/TIM/리드 경계선, 핫스팟·보이드 위치 표시)
- 같은 접속 안에서 확인한 기록을 표로 쌓는다 (새로고침하면 사라짐)
- **완료 기준**: 해석기 자체 검사(9/9)를 통과한 코드를 그대로 쓴다. 수정하지 않는다

### F5. 보이드 위험 지도 (P1)
- 가로 보이드 위치 × 세로 보이드 크기, 색 = 보이드 때문에 오른 온도
- 나머지 조건은 F1 슬라이더 값을 따른다. 슬라이더를 바꾸면 지도가 다시 그려진다
- 핫스팟 위치 표시, 마우스를 올리면 값 표시
- 불확실성이 큰 칸은 빗금 처리
- 화면에 "2D 해석으로 그리면 약 1시간 40분, 대리모델로 n초" 를 실제 측정값으로 표시
- **완료 기준**: 2,000칸 이상, 1초 이내

### F6. 허용 보이드 크기 역산 (P1)
- 입력: 온도 한계(예 85℃), 보이드 위치
- 출력: 그 위치에서 허용되는 최대 보이드 폭
- **보수적으로 계산한다**: 평균 예측이 아니라 **95% 범위의 위쪽 끝**이 한계를 넘지 않는 크기를 답한다
- 답이 학습 범위(4mm)를 넘으면 "4mm까지는 한계 이내" 로 표시하고 그 이상은 추정하지 않는다
- **완료 기준**: 역산 결과를 F4 정답 확인으로 검사했을 때 실제 온도가 한계 이하

### F7. 설명 탭 (P1)
- 이 도구가 무엇을 계산하는지 그림 한 장 + 다섯 문장
- 검증 결과 요약: 외부 검증 그래프, 학습 곡선, 오차 분석
- GitHub 저장소와 KCS 초록 링크
- AI 도구 사용 고지

### F8. 영문 전환 (P2)
- 해외 연구실 컨택이나 영문 포스터에 쓸 경우

## 9. 기술 구조

```
thermal-analysis/
  app/
    streamlit_app.py     화면
    model.py             대리모델 불러오기, 예측, 불확실성, 역산
    solver_bridge.py     thermal_2d 호출 (정답 확인)
  scripts/               기존 코드, 수정하지 않고 가져다 쓴다
  data/                  기존 데이터
  requirements.txt       numpy, streamlit, plotly
```

- **Streamlit**: 파이썬만으로 웹 화면을 만든다. 기존 코드를 그대로 쓸 수 있다
- **Plotly로 그래프**: 서버(리눅스)에는 맑은 고딕이 없어서 matplotlib 한글이 깨진다. Plotly는 보는 사람의 브라우저 글꼴을 쓰므로 이 문제가 없고, 마우스를 올리면 값도 보인다
- **배포**: Streamlit Community Cloud (무료). GitHub 저장소와 연결

## 12. 위험과 대응

| 위험 | 대응 |
|---|---|
| 불확실성 범위가 실제와 안 맞음 | 교차검증으로 보정. 그래도 안 맞으면 ± 표시를 빼고 "검증 평균 오차" 만 표시 |
