## 1. 패키지 열 해석 대리모델 (후보 A·B 공통)

### Zhang, Liu, Chen (2025) — HBM 칩렛 접합온도·핫스팟 위치 신경망 대리모델 [원문]
arXiv:2503.04049 (학술지 게재 여부 미확인, 프리프린트)

- 대상: 3D 다층 HBM 칩렛 (TSV 적층)
- 데이터: ANSYS 유한요소 해석, 라틴 하이퍼큐브 샘플링 **13,494개**
- 입력: 층 수(1·2·4·8), 칩 두께 10~50μm, TSV 열전도율(3종), 기판·하이브리드 본딩 열전도율, 층당 발열 2~8W, 대류계수 200~10,000 W/m²·K
- 모델: 은닉층 4개(512-256-128-64) 신경망
- 정확도(시험셋): 접합온도 **평균 오차 0.34℃, 최대 2.03℃**
- 데이터 수: 2,000개로 줄여도 평균 오차 0.36℃. **2,000개 미만에서는 성능 저하**
- **물리 모델 사용 안 함.** 순수 데이터 기반. 해석적 모델을 기준선이나 보정 대상으로 쓰지 않음

→ 우리에게 주는 의미: 후보 B(HBM + 대리모델)는 이미 3D FEM 1만 3천 개로 한 연구가 있다.
  반대로 후보 A(물리로 데이터 수 줄이기)에 대해서는 **"순수 데이터 모델은 2,000개 아래에서 무너진다"는 비교 기준**이 된다.

### Lai 외 (2025) — 패키지 열저항의 머신러닝 예측 [원문]
Micromachines 16(3):350, doi:10.3390/mi16030350

- 대상: QFN, TFBGA 패키지
- 데이터: 유한요소 해석. QFN 3,234개(학습 2,587 / 시험 647), TFBGA 683개(546 / 137)
- 입력: 패키지·다이·패드 크기, 두께, 각 재료 열전도율, 주변 온도, 발열 (12~13개)
- 모델: XGBoost, LightGBM, 랜덤 포레스트, SVR, 신경망 비교 → **XGBoost 최고**, MAPE 10% 미만
- **물리 특징 사용 안 함. 데이터 수에 따른 정확도 분석 없음**

### Li 외 (2026) — 이종집적 칩 열저항 예측, 물리 가이드 BP 신경망 [원문]
Scientific Reports (PMC13013625)

- 대상: 2.5D 이종집적 (2~6층, 인터포저, 마이크로범프, TSV)
- 데이터: ANSYS 2022 R1, **1,500개** (학습 1,050 / 검증 225 / 시험 225)
- 방식: 물리 원리로 만든 입력 특징 + 첫 층 가중치 부호 제약(열전도율↑ → 저항↓ 같은 단조성) + 어텐션 + 다중 출력
- 정확도: 총 열저항 R² 0.982, 평균 오차 0.103 K/W / **최고 온도 평균 오차 2.43℃**
- 제약 없는 일반 신경망은 R² 0.968
- **신경망이 해석적 모델을 완전히 대체.** 해석적 모델 값에 보정만 학습하는 구조가 아님
- **데이터 수에 따른 정확도 분석 없음**
- 한계(저자 명시): 스칼라 값만 예측, 시뮬레이션 데이터 의존, 범위 밖 외삽 위험, 정상상태만

## 2. "물리 기준선 + 머신러닝 보정" 구조 (후보 A 의 핵심 아이디어)

### Peng 외 (2026) — 반도체 공정장비 온도 예측, 물리 기반 하이브리드 신경망 [원문]
Micromachines (PMC13027931)

- 분야: 패키징이 아니라 **공정장비 온도 제어** (인접 분야)
- 방식: 물리 모델 예측값 + CNN-LSTM 이 **나머지 오차(잔차)만 학습**
- 결과: 일반 LSTM 대비 오차 51.8% 감소, 학습 범위 밖 주파수에서 R² 0.996 (일반 LSTM 약 0.80)

→ 우리에게 주는 의미: **"물리 기준선 + 잔차 학습" 아이디어 자체는 새롭지 않다.**
  우리의 기여가 될 수 있는 건 (1) 이것을 **패키지 핫스팟 온도**에 적용하고,
  (2) **"시뮬레이션을 몇 개 덜 돌려도 되는가"를 숫자로 보이는 것**이다.
  위 1절의 패키지 대리모델 3편은 모두 순수 데이터 기반이거나 물리를 특징·제약으로만 썼고,
  **해석적 1D 저항을 빼고 핫스팟 페널티만 학습시킨 구조는 이번 조사 범위에서는 못 찾았다.**
  → **2차 조사(7절)에서 수정**: 칩 열 해석에서 "저정밀 시뮬레이션 + 잔차 학습 + 데이터 절감 정량화" 는
    T-Fusion(2025)에, 패키지 휨에서 "물리 공식 결합으로 시뮬레이션 절감" 은 박성환 외(2024)에 이미 있다.

## 3. 해석적 확산 저항 (2D 해석기의 외부 검증 후보)

### Yovanovich, Muzychka, Culham (1999) — 복합 열유속 채널 위 균일 열유속 사각형·띠 열원의 확산 저항 [원문]
Journal of Thermophysics and Heat Transfer 13(4):495–500, doi:10.2514/2.6467
PDF: https://www.mhtlab.uwaterloo.ca/pdf_papers/mhtl99-2.pdf (pypdf 로 본문 텍스트를 추출해 확인)

다루는 문제 (원문 Fig. 1, Eq. 5~10)
- 2층 채널 (두께 t1, t2 / 열전도율 k1, k2), 층 사이 완전 접촉
- 열원 반대쪽 면: 균일 대류계수 h (Robin 경계)
- 옆면: 단열
- 열원: 균일 열유속 사각형(2a × 2b) 또는 **띠(폭 2a, 깊이 전체)**, 열원 밖 표면은 단열

핵심 식
- R_total = R_s + R_1D,  R_1D = t1/(k1·A) + t2/(k2·A) + 1/(h·A)   (Eq. 2, 3)
  → **우리가 제안한 "1D 값 + 핫스팟 페널티" 분해와 같은 구조가 이미 해석적으로 정립돼 있다.**
- R_s 정의: (열원 면적의 평균온도 − 열원이 있는 면 전체의 평균온도) / Q   (Eq. 11~13)
  → **최고 온도가 아니라 평균 온도 기준.** 우리 penalty(최고 − 평균)와 그대로 비교할 수 없다.
- 띠 열원, 유한 2층 채널 (Eq. 22):
  R_s = 1/(a²·c·k1) · Σ_{m≥1} sin²(a·δ_m)/δ_m³ · φ(δ_m),   δ_m = mπ/c  (a: 열원 반폭, c: 채널 반폭)
  - 이 식은 **깊이 1m당 값(K·m/W)** 이다. Eq. 14 첫 항 1/(2a²·c·d·k1) 과 비교하면 Eq. 22 = Eq. 14 × 2d. 실제 깊이 2d 로 나눠야 K/W.
- φ(ζ) (Eq. 15):
  φ = [α·e^{4ζt1} + e^{2ζt1} + ϕ·(e^{2ζ(2t1+t2)} + α·e^{2ζ(t1+t2)})] / [α·e^{4ζt1} − e^{2ζt1} + ϕ·(e^{2ζ(2t1+t2)} − α·e^{2ζ(t1+t2)})]
  ϕ = (ζ + h/k2)/(ζ − h/k2),   α = (1 − κ)/(1 + κ),   κ = k2/k1
  - 추출된 텍스트에서 괄호 위치가 모호했다. **ϕ 가 두 항 모두에 곱해져야** t2 → ∞ 에서 원문 Eq. 17 로 줄어들고
    (원문 설명대로 대류 영향이 사라짐), κ = 1 에서 원문 Eq. 18 로 줄어든다. 두 극한을 직접 대입해 확인하고 위 형태로 정했다.
- 단일층(등방성) 띠 열원 (Eq. 23):
  k·R_s = 1/(π³ε²) · Σ_{n≥1} sin²(nπε)/n³ · [nπ + Bi·tanh(nπτ)] / [nπ·tanh(nπτ) + Bi],   ε = a/c, τ = t/c, Bi = h·c/k

우리 모델과의 관계
- 우리 2D: 띠 열원 + 대류 경계 + 옆면 단열 → **문제 구조가 같다.**
- 차이 1: 우리는 **3층**(Si/TIM/Cu). 원문 식은 2층까지.
- 차이 2: 원문은 열원이 표면에 있지만, 우리 격자는 열원이 맨 아래 칸 **중심**에 있다 → 격자 크기만큼의 오차가 예상된다 (격자를 줄이며 확인 필요).
- 후속 연구: 복합·이방성 채널, 계면 저항 포함 (Muzychka 외, mhtl04-27.pdf 등) — 미확인

→ 쓸 수 있는 곳
  1. **외부 검증 (바로 가능)**: 우리 2D 해석기를 1층(Eq. 23), 2층(Eq. 22 + 15) 조건으로 돌려
     열원 구간 평균온도로 확산 저항을 구해 비교한다. 격자를 촘촘히 할수록 해석해에 다가가는지까지 보이면
     "계산끼리 맞췄다" 를 넘어 **"발표된 해석해와 맞는다"** 가 된다.
  2. **더 강한 물리 기준선 (추가 작업 필요)**: 3층은 원문 식이 직접 맞지 않는다. 2층 근사를 쓰거나,
     같은 방법(푸리에 급수 + 층 연결)을 3층으로 확장해야 한다.
  3. **새로움 판단에 영향**: "1D + 페널티" 분해 자체는 1999년에 있었다. 우리 기여는 분해가 아니라
     **"그 분해를 대리모델에 넣으면 필요한 시뮬레이션이 몇 개 줄어드는가"** 로 좁혀야 한다.

## 6. 연구 질문 (후보 A 를 좁힌 안) — ※ 2차 조사로 그대로는 새롭지 않음이 확인됨. 수정안은 7.3 참고

> **패키지 핫스팟 온도 대리모델에서, 1D 열저항으로 계산할 수 있는 부분을 분리하고
> 발열 1W당 핫스팟 페널티만 학습시키면, 순수 데이터 모델 대비 같은 정확도에 필요한
> 시뮬레이션 수가 몇 배 줄어드는가?**

실험 설계 초안
- 모델: (1) 순수 데이터: 조건 5개 → 최고 온도 / (2) 물리+AI: 조건 → 1W당 페널티, 최고 온도 = 1D 값 + 발열 × 페널티
- 학습 데이터 수: 25, 50, 100, 200, 400, 640 개
- 같은 크기에서 무작위로 여러 번 뽑아 오차 범위 표시
- 시험: 고정된 test 160개
- **주의**: 학습 곡선을 그리면 시험셋을 여러 번 보게 된다. 그러므로 모델 설정(하이퍼파라미터)은
  시험셋을 보기 전에 **학습 데이터 안의 교차검증으로만** 정하고 고정한다.

비교 기준(1절): Zhang 외는 순수 신경망이 2,000개 미만에서 성능 저하, Li 외는 1,500개로 최고 온도 평균 오차 2.43℃.
단, 문제 구조(3D FEM vs 우리 2D)가 달라 **숫자를 직접 비교하면 안 된다.** 경향 비교에만 쓴다.

## 7. 2차 조사 — 6절 질문이 이미 있는지 확인 (2026-09-13)

방법: 웹 검색 + OpenAlex·Crossref API 조회 + DOI 별 초록 조회. 검색어: multi-fidelity, grey-box, residual/delta learning,
compact thermal model + ML, thermal resistance network + neural network, 한국어(KCI) 패키지 열해석 머신러닝.
arXiv·Semantic Scholar API 는 요청 제한(429)으로 실패.

### 7.1 새로 찾은 겹치는 연구

**T-Fusion** — Zhang, Xing, Zhao, Sun (ASP-DAC 2025, pp.1406–1412) [원문: 발표 슬라이드 + 초록]
- 대상: 3D-IC 칩 열 분포 (단일코어 2층, 4코어 3층, 8코어 2층 칩)
- 입력: 무작위 **전력 분포(power profile)** — 패키지 재료·치수 변수가 아님
- 저정밀 데이터 = **성긴 격자 시뮬레이션**, 고정밀 = 촘촘한 격자 (슬라이드 "Low Fidelity Mesh / High Fidelity Mesh")
  - 1차 요약 도구가 "저정밀 = HotSpot" 이라고 했으나 **틀림.** HotSpot 은 속도 비교 대상일 뿐
- 구조: 저정밀 모델 + 텐서 곱 + **잔차 모델** (슬라이드) → **잔차 학습을 쓴다**
- 데이터: **고정밀 20개 + 저정밀 64개로 오차 1K 미만** (과도 해석), "단일 충실도 ML 대비 학습 데이터 최대 10,000배 절감"
- 코드 공개: github.com/IceLab-X/FidelityFusion

**ARO** — Wang, Cheng, Zeng, Lu, Pavlidis, Xing (ICCAD 2024) [초록]
- 3D-IC 열 확산 연산자 학습, 전력 트레이스 → 온도 분포
- 다중 충실도 융합 + 능동 학습, **무작위 샘플링 대비 데이터 25% 이상 절감**
- 저정밀 데이터가 무엇인지는 초록에 없음 (미확인)

**박성환, 김태현, 이은호 (성균관대학교)** — 몰드 경화 공정 중 패키지 휨 예측을 위한 비용 절감형 머신러닝 방법
마이크로전자및패키징학회지 31(3), 2024 [초록 요약 페이지]
- 경화도·기계 물성을 특성화해 **휨 공식을 제안**, FEM 과 비교 검증
- **휨 공식을 머신러닝 입력 변수로 사용**해 학습 데이터를 효율적으로 구성
- 예측 정확도 98% 이상, **시뮬레이션 시간 96.5% 절약**
- 미확인: 사용한 ML 모델, 순수 데이터 모델과의 비교 여부, 시뮬레이션 개수(몇 개 → 몇 개)
- → **같은 발상(물리 공식 결합으로 FEM 줄이기)이 목표 학회 쪽 학회지에 휨 주제로 이미 실렸다.**

### 7.2 겹치지 않는 것으로 확인한 연구

- **MFIT** (Pfromm 외, arXiv 2410.09188, 2024) [원문]: 세밀 FEM → 단순화 FEM → 열 RC → 이산 상태공간의 물리 기반 다중 충실도. **머신러닝 없음**
- **Calmidi & Mahajan** (IEEE Trans. CPMT Part C, 1998) [초록]: 3D 전도 해석 결과로 신경망 학습 + 대수식 결합해 플립칩 비아 최적화. 데이터 수 분석 없음. 역사적 선례로 인용 가능
- **Barua, Udoy, Aziz** (arXiv 2604.03290, 2026) 3D IC 다중스케일 열 모델링 리뷰 [초록]: 물리 기반 ML, 다중 충실도를 다룸. 데이터 효율은 초록에 없음. 과제로 TIM 변동성·계면 열저항, 실측 검증 필요성 제시
- **IC-ThermBench** (Hang 외, arXiv 2608.23977, 2026) [초록]: 2.5D/3D-IC 열 학습 벤치마크, 5만 개 칩렛 데이터. 분포 밖 사례에서 **라벨 10개로 적응 시 MAE 2.60K**
- 미확인(초록 없음): IGBT 전기-열 모델 + 딥러닝 하이브리드 (Microelectronics Journal 2026, 10.1016/j.mejo.2026.107133), 고열유속 소자 하이브리드 딥러닝 대리모델 (SSRN 2026, 10.2139/ssrn.7128856)

### 7.3 결론과 수정안

**6절 질문을 그대로 쓰면 새롭지 않다.**
- "싼 모델 + 비싼 시뮬레이션 조금 + 나머지만 학습 + 데이터 절감을 숫자로" → **T-Fusion(칩 열)에 있다**
- "물리 공식을 결합해 FEM 을 줄인다" → **박성환 외(패키지 휨)에 있다**
- "1D + 확산 저항 분해" → **Yovanovich 외(1999)에 있다**

**이번 조사 범위에서 아직 못 찾은 조합** (좁은 빈틈. 학부생 학술대회 수준의 기여)
1. **패키지 설계 변수**(TIM 두께·열전도율, 핫스팟 크기, 방열판)에 대한 열 대리모델에서 — T-Fusion·ARO 는 칩 전력 분포
2. 저정밀 **시뮬레이션**이 아니라 **계산 비용이 0인 닫힌 형태 해석해**(1D 직렬 + 확산 저항)를 기준선으로 쓰고 — T-Fusion 은 저정밀 시뮬레이션도 돌려야 함
3. **기준선의 물리 수준**(없음 / 1D 만 / 1D + 확산 저항)에 따라 필요한 고정밀 시뮬레이션 수가 어떻게 달라지는지 비교
4. 2D 해석기를 발표된 해석해(Yovanovich 1999)로 외부 검증

수정안 A-1 (위 1~4 모두)
> 패키지 핫스팟 온도 대리모델에서, 기준선으로 쓰는 해석해의 물리 수준(없음 / 1D / 1D + 확산 저항)을 높일수록
> 목표 정확도에 필요한 고정밀 시뮬레이션 수는 몇 개로 줄어드는가?

수정안 A-2 (가벼운 안)
> 박성환 외(2024)가 휨에서 보인 "물리 공식 결합 대리모델"을 패키지 열 문제로 옮기면, 1D 해석해 기준선이
> 순수 데이터 모델 대비 필요한 시뮬레이션 수를 몇 배 줄이는가?

어느 안이든 T-Fusion, ARO, 박성환 외(2024), Yovanovich 외(1999) 를 **반드시 인용하고 차이를 명시**해야 한다.
